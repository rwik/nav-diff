# NAV Diff

## Overview

**NAV Diff** is a tool that allows users to compare their own input NAV value with the current NAV of a selected mutual fund. 
This helps investors track fund performance and analyze value differences.

## Features

- **User Input NAV Comparison** – Enter a NAV value and compare it with the latest mutual fund NAV.
- **Real-Time NAV Fetching** – Automatically retrieves the latest NAV for selected funds.
- **Investment Decision** – Choose to invest on mutual funds where nav differenceis 5%+.
- **Simple & Intuitive UI** – Designed for ease of use with a clean interface.
